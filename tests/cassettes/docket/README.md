# Docket cassettes

**Synthetic, by design.** The probe loads one page per portal and never searches, so no real
portal response was recorded for these adapters (a search by name returns real people's cases). The
files in each state's folder are hand-built in the shape the adapter expects (the shape itself is
an assumption listed in `docs/sources.md`) with invented names; replace them with recordings only
for a search the operator has cleared and run themselves.
