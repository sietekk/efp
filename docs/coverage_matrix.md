## Why a state is not automated

- **MN** (manual, 138 rows): no release archive or search: releases are reachable only from curated pages, with no index to walk
- **FL** (manual, 89 rows): the site answers HTTP 403 to automated requests (checked 2026-11-22)
- **NC** (manual, 82 rows): the site answers HTTP 403 to automated requests (checked 2026-11-22)
- **WI** (manual, 68 rows): releases are published as PDF files only; reading them needs the optional PDF reader
- **KY** (manual, 62 rows): the news list is loaded by script ('Load more'); the server returns no list or feed
- **IN** (manual, 59 rows): the newsroom list is loaded by script; the page carries no server-rendered releases, feed or archive
